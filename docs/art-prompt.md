# Art prompt for Grand Hotel

Ask the image AI for **contact sheets, not single images**: one image holding a whole set in a grid.
Sets made together come out far more consistent (same faces, line weight and colours) than images made
one by one. Paste the **style brief** once, then send one sheet request at a time.

Each sheet below lists its grid and what goes in every cell, in reading order (left to right, top to
bottom). Once a sheet looks right, cut it into cells and save each cell under the file name shown, so the
game can pick the images up by name.

---

## Style brief (paste this first)

> You are illustrating **Grand Hotel**, a cosy board-game app set in a grand hotel in Vienna around 1905.
> The look is a **modern, flat editorial illustration with a Viennese Secession (Jugendstil) touch**:
> clean shapes, soft paper grain, thin ink outlines, gentle shading, no photorealism, no 3D render look.
>
> **Palette**: warm ivory paper `#F6F1E8`, deep navy `#1E2A44`, muted gold `#C99A2E`,
> and four category colours used as accents: red `#B3473C`, yellow `#C99A2E`, blue `#3D6AA3`, green `#4C8656`.
> Skin tones and clothing in natural, slightly desaturated period colours.
>
> **Characters**: friendly, a little whimsical, period-accurate Edwardian / Belle Époque clothing.
> Head-and-shoulders bust, three-quarter view, looking slightly towards the viewer, neutral pose,
> centred in frame with some headroom. Every character is an original invented person
> (do not depict real historical figures or copy existing board-game artwork).
>
> **Contact sheets**: always deliver a set as ONE contact sheet: a single image with a strict grid of
> equal square cells separated by thin, even ivory gutters, filled left to right, top to bottom, in the
> order given. Every cell is a complete, separate illustration with its own flat background; nothing
> crosses into a neighbouring cell. Leave any spare cells plain ivory.
>
> **Inside each cell**: subject fills about 70% of the cell, centred, plain flat background in the
> requested tint. No text, letters, numbers, captions, labels, borders, frames, watermarks or logos
> anywhere on the sheet. Each portrait must stay readable when cut out and shown as a 48 px circle.
>
> **Consistency**: same line weight, same lighting (soft light from upper left), same level of detail
> and the same palette across every image in the set.

---

## How to ask for each sheet

> Using the style brief, make **one contact sheet**: a 4 × 4 grid of square cells on a 2048 × 2048 image,
> thin ivory gutters, filled left to right, top to bottom in this order: [paste the cell list].

If a cell comes out wrong, ask for the whole sheet again with a note ("cell 7 should be holding a quill")
rather than a single replacement image, so the set stays consistent.

## Cutting the sheets

Every sheet is a regular grid, so each cell is `(sheet width ÷ columns)` wide. Cut along the gutters
(any image editor's slice tool or a batch-crop script works), trim the gutter, and save each cell under
the name in the table. Check a few at 48 px before finishing a batch; if faces turn to mush, ask for the
sheet again with "simpler shapes, larger features".

## Delivery checklist

- PNG, sRGB, exact file names above.
- No text anywhere in the images.
- One sheet per set, all cells in the listed order.
